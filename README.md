# devenv-cloud

Docker-first private developer platform — a single-repository, Docker-first setup for remote development, agent-assisted coding, GitHub automation, durable orchestration, and governance/observability, running primarily on one Linux server.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for a condensed C4-model overview, [`docs/INITIAL.md`](docs/INITIAL.md) for the full implementation plan, and [`docs/phases/`](docs/phases/README.md) for the phased delivery breakdown, starting with **Phase 1 — Remote Dev Environment + Agent**.
