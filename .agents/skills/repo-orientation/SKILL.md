# Repo orientation

When asked to get oriented in this repository, always check, in this order:

1. `AGENTS.md` at the repo root - accumulated lessons learned and the
   `make` target reference table.
2. `docs/ARCHITECTURE.md` - condensed C4-model view of the platform.
3. `docs/INITIAL.md` - the authoritative implementation plan.

Never guess at a `make` target name - look it up in `AGENTS.md`'s table
first.
